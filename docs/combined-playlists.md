# Объединённые плейлисты

В Android 0.16.0 нажми «Создать плейлист», введи название и отметь минимум два
источника. Без выбранных источников создаётся обычный пустой плейлист.
Объединение можно слушать, скачивать, фильтровать и включать для него DJ-режим.
Его состав нельзя случайно отредактировать как обычный плейлист: действие
удаления песни из источников здесь не показывается. Старые APK не получают
объединения, пока не научились отображать их без опасных действий над источником.

Объединение хранит название и ссылки на 2–30 обычных плейлистов. Песни и папки
на Яндекс Диске остаются на своих местах. Добавление, удаление и перестановка
в исходных плейлистах сразу отражаются в объединении при обновлении каталога.

Порядок: сначала первый выбранный источник, затем новые песни из остальных.
Одинаковый MD5 встречается один раз; используется идентификатор первого
вхождения. Оценки, DJ-разметка, файлы и локальные загрузки используют прежние
глобальные записи песен.

Определения лежат в таблице `playlist_combined` базы `bot.sqlite`.
`sources` содержит упорядоченный JSON-массив обычных ID. Публичный ID равен
`900001000 + id`. Вложенные объединения и служебные коллекции источниками
быть не могут. Одновременно разрешены до 30 объединений. Названия уникальны
среди обычных и объединённых плейлистов без учёта регистра.

Каталог возвращает `combinedSupported: true` и записи вида:

```json
{
  "id": 900001001,
  "name": "Volleyball + Предложка",
  "combined": true,
  "sourcePlaylistIds": [1, 2],
  "trackIds": ["existing-global-track-id"],
  "revision": "20-hex-characters"
}
```

`POST /api/edit` принимает следующие действия:

- `combine`: `name`, `sourcePlaylistIds`, `opId`.
- `rename-combined`: `playlistId`, `name`, `revision`, `opId`.
- `delete-combined`: `playlistId`, `revision`, `opId`.

Определение и завершённая квитанция `web_operations` записываются одной
транзакцией. Повтор того же запроса безопасен; использование `opId` для другого
действия или содержимого отклоняется. Изменившаяся ревизия возвращает конфликт.
Ревизия учитывает название, порядок источников и текущие ID/MD5 песен.

Объединение можно переименовать или удалить, но менять его состав вручную
нельзя: для этого редактируют исходные плейлисты. Удаление объединения удаляет
только определение. Список обычных плейлистов бота остаётся прежним.

Штатная резервная копия сохраняет определения и счётчик ID, включая ранее
удалённые объединения. Старые резервные копии без этой таблицы поддерживаются;
таблица создаётся штатной миграцией при подключении базы. Изменения попадают
на другие устройства через существующую ревизию библиотеки.
